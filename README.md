# 🎵 Music-CS 

A modern, high-fidelity YouTube Music interface clone built with **HTML5**, **Tailwind CSS v4**, and custom **CSS animations**. Designed as a responsive web app showcase featuring a dark-mode aesthetic, playlist grids, an interactive bottom player bar, and a Music Premium promotional banner.

---

## ✨ Features

- **YouTube Music Interface:** Authentic dark theme with signature red accents (`#EF4444`), top navigation bar, and integrated search styling.
- **Category Filter Pills:** Interactive scrollable filter tags (*Energize, Focus, Relax, Workout, Commute*).
- **Quick Picks Grid:** Compact track rows with custom hover states, play button overlays, and action menus.
- **Recommended Albums:** Responsive image grid featuring ambient red glow effects (`yt-glow`) and floating play controls.
- **Get Music Premium Banner:** High-converting promotional section showcasing ad-free features and call-to-action buttons.
- **Sticky Audio Player:** Persistent bottom control bar with live progress indicators, track details, thumbs up/down feedback, and mode switcher tabs (*Song / Video / Up Next*).

---

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic structure and accessible markup.
- **Tailwind CSS v4:** Utility-first CSS styling using modern `@theme` directive integration.
- **CSS3:** Custom animations and ambient box-shadow glow effects.
- **Git & GitHub:** Version control and source management.
